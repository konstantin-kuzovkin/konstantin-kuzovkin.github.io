About

Senior / Lead System Analyst focused on solution and integration architecture for distributed, microservice-based systems in banking.

My experience covers distributed transactions, event-driven architecture, API and event contracts, platform architecture and workflow orchestration, with a strong focus on reliability, consistency, idempotency, failure handling and reconciliation.

I work with REST/OpenAPI, SOAP/XML, Kafka/AsyncAPI, BPMN/Camunda, UML, ERD, data modelling and authentication/authorization.

I also contribute to architecture standards, architecture reviews, cross-team solution alignment and functional leadership without formal people management.

One of my recent engineering initiatives is an AI-assisted system analysis agent based on LLMs, controlled tools and specialised analytical agents, using source-grounded analysis, evidence provenance and explicit hallucination controls.
